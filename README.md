# mascotes

## Install in Codex

1. Download just the mascot you want — grab its `.zip` from the table below and unzip it (each zip is one mascot: `pet.json` + `spritesheet.webp`). Or download the whole repo (**Code → Download ZIP**).
2. In Codex: **Settings → Pets → Create pet**, and point to the unzipped mascot folder.
3. If you prefer to do it by hand: copy the folders from `pets/` into `C:\Users\<your user>\.codex\pets\` (Windows) or `~/.codex/pets/` (Mac and Linux), then reopen Codex.

`Alt+Win+P` shows and hides the pet on screen.
