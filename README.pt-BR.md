## Instalar no Codex

1. Baixe só o mascote que você quer — pegue o `.zip` dele na tabela abaixo e descompacte (cada zip é um mascote: `pet.json` + `spritesheet.webp`). Ou baixe o repositório inteiro (**Code → Download ZIP**).
2. No Codex: **Configurações → Mascotes → Criar mascote**, e aponte para a pasta do mascote descompactada.
3. Se preferir fazer à mão: copie as pastas de `pets/` para `C:\Users\<seu usuário>\.codex\pets\` (Windows) ou `~/.codex/pets/` (Mac e Linux) e reabra o Codex.

`Alt+Win+P` mostra e esconde o mascote na tela.
